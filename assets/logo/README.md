# Logo

Sleeping Docker whale: the Moby whale with a nightcap over the containers on its back,
closed eye and optional "zZz".

| File | Use |
| --- | --- |
| `sds-logo.svg` | main logo (nightcap + zZz), 128×128 viewBox |
| `sds-logo-plain.svg` | nightcap only, no zZz |
| `sds-logo-512.png`, `sds-logo-plain-512.png` | raster previews, 512×512 |
| `sds-logo.vectorcraft` | editable master (groups `nightcap`, `closed eye`, `zzz`) |

Source of the whale: the Docker icon from <https://techicons.dev/icons/docker>
(<https://icon.icepanel.io/Technology/svg/Docker.svg>). The Docker whale is a trademark of
Docker, Inc.; this derivative is used only to identify the project's relation to Docker.
The nightcap, closed eye and zZz are original additions.
